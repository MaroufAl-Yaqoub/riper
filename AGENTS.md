\# Instructions for Codex



This project contains:



\- Flutter app in ndpp\_app/

\- Python backend in ndpp-backend/ndpp-backend/

\- AI models stored using Git LFS in ai/artifacts/



\## Setup



Backend:

\- Go to ndpp-backend/ndpp-backend/

\- Run: pip install -r requirements.txt



AI:

\- Run: git lfs pull



\## Notes



\- Do NOT modify AI models

\- Do NOT commit .env

\- Focus on improving code only
